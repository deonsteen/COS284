# COS284

Practicals for COS284 (Computer Organisation and Architecture), written in x86-64 assembly (yasm).

Each practical lives on its own branch:

| Branch  | Contents      |
|---------|---------------|
| `Prac2` | Practical 2   |
| `Prac3` | Practical 3   |

Inside a practical branch:

```sh
make        # assemble and link all tasks
make test   # run the test suite
make clean
```
